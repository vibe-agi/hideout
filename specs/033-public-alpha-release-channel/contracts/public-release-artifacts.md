# Contract: Public Release Artifacts

## Exact Asset Allowlist

For `v0.1.0-alpha.1`, the immutable GitHub prerelease contains exactly:

```text
hideout-v0.1.0-alpha.1-darwin-arm64.tar.gz
hideout-v0.1.0-alpha.1-evidence.tar.gz
hideout-v0.1.0-alpha.1-release.json
SHA256SUMS
```

No receipt is uploaded after publication. Source archives generated by GitHub
are not Hideout package assets and are excluded from the product checksum set.

Schema: `hideout.public-release/v1`

Rules:

- Additional properties, duplicate artifacts, duplicate basenames, mutable
  `latest` URLs, zero-byte artifacts, unsupported targets, dirty source, and
  control-plane material fail.
- Every digest is lowercase SHA-256 and every size equals the actual file.
- `catalogFileSHA256` equals the package manifest entry for
  `runtime/catalog.json`; it is not a new catalog-wide hash.
- `developer-id-verified` requires an independently validated signing
  observation for every host Mach-O.
- `accepted` notarization requires a validated observation for the private ZIP
  envelope made from the same frozen package tree.
- `developer-preview-unsigned` is valid only for a distinct developer-preview
  version/channel and cannot render as public supervised alpha.
- The project license does not claim to cover third-party components.

## SHA256SUMS

- Covers package, evidence bundle, and release manifest; never itself.
- Uses exactly two spaces between digest and basename.
- Is sorted by bytewise basename.
- Contains no path separator, absolute path, duplicate name, extra asset, or
  unsupported digest algorithm.
- Must agree with both pre-upload bytes and GitHub's post-upload asset digest.

## Package Archive

- One top-level `hideout/` directory.
- Regular files/directories only; no symlink, hard link, device, absolute path,
  `..`, duplicate normalized path, or owner-dependent absolute metadata.
- Includes the canonical package manifest, package installer,
  binaries/helpers, schemas, runtime catalog/contract/build provenance,
  Apache-2.0 `LICENSE`,
  `THIRD_PARTY_NOTICES.md`, `SECURITY.md`, and channel-neutral README files.
- Includes no runtime image, profile, store, credential, local evidence path,
  source checkout path, or workflow secret.

## Signing/Notarization Claim

The release may say:

> Host Mach-O executables in this package were independently observed as
> Developer ID signed and the frozen signed package tree was accepted by
> Apple's online notarization service through the recorded ZIP submission.

It may not say the distributed `tar.gz` is stapled or that notarization is an
Apple security review.
