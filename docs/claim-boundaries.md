# Claim Boundaries

<!-- markdownlint-disable MD013 -->

This registry maps current product claims to the document that owns the claim
and the proof or gate that backs it. It is intentionally compact; detailed
contracts remain in the linked docs and specs.

## Rules

- Local-fast product-hardening proof is usability/regression evidence, not
  release readiness.
- Real backend, DNS, network, and HostFS data-plane claims require the named
  real gate.
- Native backend is always a development harness, not isolation evidence.
- `.tmp` discussion drafts are planning material and are not current product
  truth.
